# AGENTS.md — Проект дома (сайт)

## Обзор проекта

Статический одностраничный сайт про инженерные системы частного дома (~100 м²): электрика 15 кВт 3 фазы, тёплые полы, водоподготовка, септик Евролос. Публикуется на GitHub Pages на кириллическом домене `xn--80aafnllbhmt7bd6j.xn--p1ai` (IDN, punycode).

**Технологический стек — специально минимальный: чистый HTML/CSS/JS без сборки, без пакетного менеджера, без фреймворков.** Нет `package.json`, `pyproject.toml` и т.п. Это сознательное решение — не добавлять тулчейн без необходимости.

## Структура

```
index.html      — главная страница (~1300 строк): вся верстка, стили и JS inline
schema.html     — страница-схема: вводная схема электроснабжения (SVG, светлая тема)
voda.html       — страница-схема: ввод воды и водоподготовка (SVG, тот же шаблон, что schema.html)
photos/         — 8 фотографий со стройки (.jpg), используются в галерее на index.html
CNAME           — кастомный домен для GitHub Pages
robots.txt      — разрешает всё, ссылается на sitemap.xml
sitemap.xml     — 3 URL (index + schema + voda), поле lastmod обновлять при правках контента
```

## Архитектура и конвенции кода

- Весь CSS и JS живут **inline внутри HTML-файлов** (`<style>` в `<head>`, `<script>` в конце `<body>`). Отдельных файлов нет и не нужно.
- Язык контента и комментариев в коде — **русский**. CSS-комментарии в `index.html` секционные: `/* ---------- навигация ---------- */`.
- Стили организованы через CSS-переменные в `:root` (цвета, шрифты, радиусы) — использовать их, не хардкодить значения.
- Шрифты: Google Fonts (Unbounded для заголовков `--font-d`, Manrope для текста `--font-b`). `schema.html` и `voda.html` используют системный шрифт-стек и светлую тему — у страниц разный визуальный стиль, это намеренно. Обе страницы-схемы — производные от `site/*.html` приватного репо `project-doma`; править исходники там, сюда переносить с панелью `tabnav`.
- Секции `index.html` имеют id-якоря: `#numbers`, `#systems`, `#water`, `#power`, `#heat`, `#photos`, `#smeta`, `#roadmap`.
- Анимации на главной: **GSAP 3.12.5 + ScrollTrigger** и **Lenis 1.1.14** (плавный скролл), подключены с CDN jsDelivr в конце `index.html`. При правках стилей скролла учитывать классы Lenis (`html.lenis` и т.д.).
- Изображения подключаются относительными путями `photos/*.jpg` — без внешних URL.

## Сборка, тестирование, деплой

- **Сборки и тестов нет.** Проверка правок — открыть файл локально: `open index.html` (или `python3 -m http.server`).
- **Деплой = push в репозиторий**, GitHub Pages раздаёт файлы как есть. Ничего не билдить.
- При добавлении новой страницы: добавить её в `sitemap.xml` и обновить `lastmod`.
- Проверять, что относительные пути и якорные ссылки не сломаны; домен в `CNAME`, `robots.txt`, `sitemap.xml` должен оставаться согласованным (punycode).

## Замечания по безопасности

- Нет бэкенда, форм, пользовательских данных — поверхность атаки минимальна.
- Внешние зависимости только через CDN (Google Fonts, jsDelivr) — при обновлении версий фиксировать конкретную версию, как сейчас.
